**Udemy-clone**

This project is a responsive Udemy Clone Website developed using HTML5 and CSS3. The main objective of this project is to recreate
the user interface of the popular online learning platform Udemy while improving front-end web development skills. 
The website contains a modern and clean design that provides a smooth user experience across desktop, tablet, and mobile devices.

The project includes multiple sections such as a navigation bar, search bar, featured banner, course categories, recommended courses, 
top trending courses, and footer section. The layout is designed using modern CSS techniques like Flexbox, positioning, spacing, 
hover effects, and responsive styling.

By building this project, I gained practical experience in creating real-world website layouts, improving UI design skills, and 
understanding responsive web development concepts. This project also helped me strengthen my knowledge of HTML structure, 
CSS styling, alignment techniques, and responsive design principles.

The website is fully static and focused on front-end design implementation. It can be further enhanced by adding JavaScript 
functionality and backend integration in the future.

**Features**
* Responsive and modern homepage design
* Navigation bar with search functionality UI
* Course categories section
* Featured and recommended courses layout
* Clean user interface with hover effects
* Organized sections and responsive structure
* Mobile-friendly design
* Footer with useful links and information

**Technologies Used**
* HTML5
* CSS3
* Flexbox
* Responsive Web Design

**What I Learned**
* Building responsive website layouts
* Structuring webpages using semantic HTML
* Styling modern UI components with CSS
* Using Flexbox for alignment and spacing
* Creating reusable design sections
* Improving overall front-end development skills
