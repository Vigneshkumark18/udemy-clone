# Udemy Clone 🎓

## 📌 Project Description

This project is a Udemy Clone website developed using HTML and CSS. The main objective of this project is to recreate the design and layout of 
an online learning platform, providing a user-friendly interface for browsing and exploring courses.

## 🚀 Features

* Clean and user-friendly interface
* Navigation bar for easy browsing
* Course section with course details
* Responsive and structured webpage layout
* Attractive styling using CSS

## 🛠️ Technologies Used

* **HTML5** – For structuring the webpage
* **CSS3** – For styling and layout design

## 🎯 Learning Objectives

* Practiced HTML page structure and semantic elements
* Improved CSS styling and layout skills
* Learned to organize webpage sections
* Gained hands-on experience recreating a real-world website design

## 💻 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your browser.
